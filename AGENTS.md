# Проект: Vigsharm — Интернет-витрина цветов / подарков (Армавир)

## Суть проекта
Локальный интернет-магазин/витрина для Армавира (+ радиус 50–100 км).
БЕЗ корзины и онлайн-эквайринга. Оформление происходит напрямую из карточки товара в мессенджеры или звонком.

## Главный пользовательский сценарий
1. Клиент заходит в каталог товаров.
2. Открывает карточку / модальное окно товара.
3. Выбирает:
   - Способ получения: Доставка (по Армавиру и до 100 км) или Самовывоз.
   - Дату и время (интервал).
   - При необходимости: текст открытки / пожелания к заказу.
4. Нажимает кнопку отправки заявки:
   - WhatsApp (генерируется готовый текст сообщения с названием товара, ценой, датой, временем и адресом/самовывозом).
   - Telegram (переход в чат или бот с готовым текстом).
   - Быстрый звонок на номер магазина.

## Стек и архитектура
- Быстрый, легковесный фронтенд (чистый HTML/CSS/JS или современный легковесный фреймворк без громоздкого бэкенда).
- Адаптивность: 80%+ заказов идет с мобильных телефонов (Mobile First!).
- Все токены стилей берутся строго из `DESIGN.md`.

## Правила для агента (Строгие запреты!)
1. НЕ предлагать и не внедрять корзину с оплатой картой на сайте. Заказ уходит в мессенджер.
2. НЕ менять дизайн-токены (цвета, шрифты) самовольно без разрешения.
3. Перед внесением крупных изменений ВСЕГДА сначала писать план шагов. Код писать только после утверждения.
4. Не создавать «типовой серый AI-дизайн» с фиолетовыми неоновыми кнопками.
