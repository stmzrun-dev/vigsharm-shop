# Changelog — VigSharm Admin

## [1.1.0] - 2024-01-XX

### Изменено
- Полностью переработан дизайн в соответствии с предыдущей версией
- Новая цветовая палитра: голубые акценты, светлые фоны, градиентные кнопки
- Улучшенная типографика и отступы
- Обновлены стили для форм, кнопок, badge, модальных окон
- Трёхколоночная сетка для чекбоксов категорий
- Улучшенная галерея фотографий с подписями и круглыми кнопками действий
- Hero-секции с градиентными фонами для каждого раздела
- Логотип "ВигШарм" с градиентом в шапке

## [1.0.0] - 2024-01-XX

### Добавлено
- Первая версия админ-панели
- Загрузка и управление фотографиями товаров (до 6 фото × 10MB)
- Интеграция с OpenAI для генерации описаний
- Интеграция со Studio Pro (Nord Router) для обработки фото
- CRUD операции: создание, редактирование, публикация товаров
- Поддержка черновиков
- Выбор категорий, тегов и сцен
- Адаптивный дизайн
- Валидация форм

### Технологии
- Vanilla JS (ES6+)
- Cloudflare D1 (база данных)
- Cloudflare R2 (хранение изображений)
- OpenAI API
- Nord Router API
