## 📸 Настройка Cloudinary (5 минут)

### Шаг 1: Получить Cloud Name

1. Откройте https://console.cloudinary.com/
2. На главной странице (Dashboard) вы увидите:
   ```
   Cloud Name: dxxxxx
   ```
3. **Скопируйте это значение**

---

### Шаг 2: Создать Upload Preset (без подписи)

1. В Cloudinary Dashboard перейдите: **Settings** (⚙️ справа вверху)
2. Выберите вкладку **Upload**
3. Прокрутите вниз до раздела **Upload presets**
4. Нажмите **Add upload preset**

#### Настройки preset:
- **Preset name**: `vigsharm_unsigned` (любое имя)
- **Signing Mode**: выберите **Unsigned** ⚠️ ВАЖНО!
- **Folder**: `vigsharm-products` (опционально, для организации)
- **Unique filename**: ✅ включить (чтобы избежать конфликтов)
- **Overwrite**: ❌ выключить

5. Нажмите **Save**
6. **Скопируйте имя preset** (например: `vigsharm_unsigned`)

---

### Шаг 3: Настроить админку

1. Откройте `c:\vigsharm-shop\admin\index.html` в браузере
2. Перейдите на вкладку **Настройки**
3. В разделе **Cloudinary** введите:
   - **Cloud Name**: `dxxxxx` (ваше значение)
   - **Upload Preset**: `vigsharm_unsigned` (имя созданного preset)
4. Нажмите **Сохранить**

## 🔧 Troubleshooting

### Фото не загружаются
1. Проверьте, что Upload Preset создан как **Unsigned**
2. Проверьте правильность Cloud Name и Upload Preset в настройках
3. Откройте консоль браузера (F12) для ошибок

### Ошибка CORS
- Unsigned upload preset автоматически разрешает CORS
- Если проблема сохраняется, добавьте домен в Cloudinary Settings → Security → Allowed domains

### Медленная загрузка
- Cloudinary автоматически оптимизирует и сжимает фото
- Первая загрузка может занять несколько секунд
