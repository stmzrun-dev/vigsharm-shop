# DESIGN.md — Vigsharm

## Философия (гибрид)
**База — studio:** белый фон, воздух, тонкие рамки, спокойный UI. Главный герой — реальные / качественные фото шаров и композиций.

**Праздник — точечно:** коралл из логотипа (`--accent`) + максимум 1–2 «искорки» на экран из радуги wordmark (слово «всё!», короткая линия). Не весь экран в радуге и пастели.

Интерфейс не спорит с фото. Clay / 3D-игрушечный язык — только для отдельных иллюстраций, не для кнопок, карточек и футера.

## Цвета (UI)
```
--bg:           #FFFFFF
--surface:      #FFFFFF
--text:         #2A2A32
--text-muted:   #6F6F78
--eyebrow:      #8B8B93
--line:         #E8E8EC
--line-strong:  #D8D8DE
--accent:       #FF6B5A
--accent-hover: #E85A4A
```

`--accent` = coral из буквы «В» логотипа. Primary-кнопки и ключевые UI-метки — только он.

Мессенджеры (только иконки/кнопки связи, не общий UI):
- WhatsApp `#25D366`
- Telegram `#229ED9`

## Палитра логотипа (бренд)
Источник: wordmark «ВИГШАРМ» + шарики рядом. Порядок букв = радуга слева направо:

| Буква | Роль | Ориентир |
|---|---|---|
| В | coral / UI-акцент | `#FF6B5A` |
| И | orange | `#FF9A3D` |
| Г | yellow | `#F5C518` |
| Ш | green | `#4CBF3F` |
| А | cyan | `#2EC4D6` |
| Р | blue | `#3B6FE8` |
| М | purple | `#8B5CF6` |

Подпись логотипа «СТУДИЯ АЭРОДИЗАЙНА» — графит `#4A4A52`, не цветной.

**Как использовать радугу логотипа**
- Можно: логотип как есть; слово «всё!» (pill / градиент по этой шкале); одна короткая линия под заголовком; декоративные блёстки рядом с логотипом.
- Нельзя: семь цветов на кнопки/карточки/иконки; радужный фон секции; радужный CTA на всю кнопку; «каждая карточка своего цвета радуги».

Радуга логотипа — **праздничный акцент**, не системная UI-палитра. На экран максимум 1–2 таких искорки.

## Типографика
- Заголовки: жирный sans (как на живой главной), `letter-spacing: -0.03em`, вес ~800.
- Текст: тот же семейный стек сайта, 15–17px, `line-height: 1.5`.
- Eyebrow: uppercase / tracking `0.06em`, цвет `--eyebrow`, вес 700.
- Максимум два визуальных веса на блок (обычный + жирный). Не плодить «третий акцентный» цвет в заголовках.

Не делать Inter «шрифтом по умолчанию ради красоты» — использовать стек проекта (`assets/fonts.css`).

## Ритм и форма
- Отступы секций кратны 8px; горизонтальный gutter как на главной: `max(16px…32px, calc((100% - 1280px) / 2))`.
- Радиус карточек / рамок: **18–22px** (один порядок на сайт).
- Кнопки primary: **капсула** `border-radius: 999px`, высота 48–52px, заливка `--accent`.
- Кнопки outline: белый фон, рамка `--line`, текст `--text`.
- Тень: одна мягкая, только у поднятого/открытого элемента (hover карточки, open FAQ). Не под каждым блоком.
- Иконки в chrome (футер, телефон, чат, соцсети): **line SVG**, монохром. Не toon-эмодзи со смайлами.

## Паттерны блоков (главная как эталон)
1. Hero / фото-секции — studio: белый, фото edge-to-content, без clay-фона.
2. Сетки (для кого, идеи, бюджет, герои) — ровный ритм карточек, фото впереди.
3. FAQ — белые строки с рамкой `--line`, номера `--accent`.
4. Футер — белый, CTA с рамкой, coral-капсула, line-иконки.

## Запрещено
- Фиолетовые / индиго градиенты «AI-дефолт», glow, неоновые кнопки.
- Градиентный фон у секций и радужный CTA на всю кнопку.
- Больше одного акцентного цвета UI на экран (кроме точечной радуги и брендовых цветов мессенджеров).
- Claymorphism / soft-clay как системный UI (рамки, кнопки, футер, FAQ).
- Toon-эмодзи вместо векторных line-иконок в chrome.
- Тень и «карточка в карточке» у каждого блока подряд.
- Центрированный длинный текст (>2 строк) в маркетинговых секциях.
- Менять токены самовольно без согласования.

## Мобильный фокус
- Ширина проверки: **375px**.
- CTA под палец: min-height 48px.
- Sticky «Подобрать» не перекрывает контент (достаточный `padding-bottom` у main).
- Контраст muted-текста проверять на солнце / яркости телефона.

## Как пользоваться агенту
1. Перед крупным экраном — читать этот файл.
2. Один экран / блок за раз, дальше по образцу главной.
3. Новые цвета и эффекты не добавлять «для красоты» — только из токенов или после явного «ок».
4. Саморевью не доверять: после блока — короткий чек по разделу «Запрещено» + 375px.
