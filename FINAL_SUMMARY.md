## 🔑 Ключевое открытие: Формат моделей NordRouter

```
❌ НЕ РАБОТАЕТ              ✅ РАБОТАЕТ
gpt-3.5-turbo         →    openai/gpt-4o-mini
gpt-4o-mini           →    openai/gpt-4o
claude-sonnet-4       →    anthropic/claude-sonnet-4.6
```

**Причина:** NordRouter требует префикс провайдера (openai/, anthropic/, deepseek/)

```bash
cd c:\vigsharm-shop\worker

# Введите: sk-nr-...
```

- Откройте: https://nordrouter.com
- Личный кабинет → Баланс
- Должно быть > $0.01

- Личный кабинет NordRouter
- Раздел API-ключи
- Убедитесь, что ключ имеет доступ к OpenAI
