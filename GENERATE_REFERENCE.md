# 🎨 ГЕНЕРАЦИЯ ЭТАЛОННОГО ФОНА

## Зачем нужен эталонный фон?

Чтобы **ВСЕ** товары были на **ОДИНАКОВОМ** фоне, нужно эталонное фото-образец.

**Проблема сейчас:**
- AI генерирует фон по текстовому описанию
- Каждый раз получается **немного разный** фон
- "Бежево-серая стена" может быть светлее/темнее/с другой текстурой

**Решение:**
- Создать **ОДНО** эталонное фото фона
- AI будет копировать фон с этого эталона
- **ВСЕ** товары → одинаковый фон

---

## Шаг 1: Генерация эталона

### Откройте генератор
```
admin/generate-reference.html
```

### Заполните форму
1. Укажите NordRouter API Key
2. Выберите композицию:
   - **🏠 Полная сцена** - стена + плинтус + пол (рекомендуется)
   - **🧱 Только стена** - без пола
   - **📸 Угловая** - с перспективой

3. Нажмите **"Сгенерировать"**
4. Ждите 1-2 минуты
5. Скачайте результат

---

## Шаг 2: Сохранение эталона

Сохраните сгенерированное фото как:
```
assets/reference-background.jpg
```

Или в любое удобное место, главное запомнить путь.

---

## Шаг 3: Интеграция в Studio Pro

После того, как эталон создан, я интегрирую его в код двумя способами:

### Вариант A: Reference Image (если поддерживается)
```javascript
// Studio Pro будет отправлять:
{
  image: "ваше фото товара",
  reference: "assets/reference-background.jpg", // эталон
  prompt: "замени фон на reference image"
}
```

### Вариант B: Style Transfer
```javascript
// Или использовать style transfer:
{
  image: "ваше фото товара",
  style: "assets/reference-background.jpg",
  prompt: "скопируй фон со style image"
}
```

---

## Как это будет работать

### ТЕКУЩАЯ система (без эталона):
```
Фото товара 1 → AI → "бежевая стена" → Результат 1 (фон А)
Фото товара 2 → AI → "бежевая стена" → Результат 2 (фон Б - немного другой)
Фото товара 3 → AI → "бежевая стена" → Результат 3 (фон В - снова другой)
```
❌ Фон разный на каждом фото

### НОВАЯ система (с эталоном):
```
               ┌─ Эталон (reference-background.jpg) 
               │
Фото товара 1 ─┼→ AI → копирует фон с эталона → Результат 1
Фото товара 2 ─┼→ AI → копирует фон с эталона → Результат 2
Фото товара 3 ─┼→ AI → копирует фон с эталона → Результат 3
```
✅ Фон **ИДЕНТИЧНЫЙ** на всех фото

## Рекомендации для эталона

### Освещение
- Мягкое, равномерное
- Без резких теней
- Нейтральный белый баланс
- **БЕЗ** желтизны

### Композиция
- Для универсальности: 60% стена, 30% пол
- Стена: светлая тёплая бежево-серая
- Пол: серо-бежевый ламинат
- Плинтус: белый

### Размер
- Квадрат 1024x1024px
- Высокое качество
- Реальное фото (не 3D render)

## Альтернатива: Фото реальной студии

Если у вас есть **фото вашей реальной студии** (пустая комната):
- Сфотографируйте пустую стену + пол
- Квадратный кадр
- Хорошее освещение
- Используйте это фото как эталон

**Преимущество:** фон будет **точно** как в вашей студии.

---

## Проверка эталона

После интеграции протестируем:
1. Загрузить 3 разных товара
2. Обработать через Studio Pro
3. Проверить, что фон **ИДЕНТИЧНЫЙ** на всех 3 фото
4. Если нужны корректировки - создадим новый эталон
