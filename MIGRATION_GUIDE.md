3. Откройте админку → вкладка **"Настройки"**

4. Заполните поля:
   - Worker API URL: `https://vigsharm-api.vigsharm.workers.dev` ✅ (уже заполнено)
   - Cloud Name: `dxxxxx` (ваше значение)
   - Upload Preset: `vigsharm_unsigned` (созданный вами)

5. Нажмите **"Сохранить"**

## 🔧 Устранение проблем

### "Товары не загружаются на сайте"
**Причина:** CORS или Worker не отвечает

**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте Network → запрос к `vigsharm-api.vigsharm.workers.dev/api/products`
3. Если 500 ошибка → проверьте Worker logs в Cloudflare Dashboard
4. Если CORS ошибка → убедитесь, что Worker возвращает заголовки CORS

---

### "Миграция завершилась с ошибками"
**Причина:** Worker не доступен или D1 база не настроена

**Решение:**
1. Проверьте, что Worker задеплоен:
   ```
   https://vigsharm-api.vigsharm.workers.dev/api/products
   ```
   Должно вернуть: `{"ok":true,"products":[]}`

2. Если 404 → переделойте Worker:
   ```bash
   cd c:\vigsharm-shop\worker
   wrangler deploy
   ```

---

### "Фото не загружаются в админке"
**Причина:** Cloudinary не настроен

**Решение:**
1. Создайте аккаунт на Cloudinary
2. Создайте Unsigned Upload Preset
3. Введите данные в админке → Настройки
