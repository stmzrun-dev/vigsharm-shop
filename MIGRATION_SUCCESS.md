2. Создайте **Unsigned Upload Preset**:
   - Settings → Upload → Upload Presets → Add upload preset
   - Signing Mode: **Unsigned**
   - Upload preset name: `vigsharm_unsigned`
3. Откройте админку: `file:///c:/vigsharm-shop/admin/index.html`
4. Вкладка **"Настройки"** → заполните:
   - Cloud Name: ваше значение из Dashboard
   - Upload Preset: `vigsharm_unsigned`
5. Нажмите **"Сохранить"**
