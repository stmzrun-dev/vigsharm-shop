## 🚀 ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС:

### Шаг 1: Настроить Cloudinary Upload Preset (5 минут)

**Откройте инструкцию:** `CLOUDINARY_SETUP.md`

Кратко:
1. Откройте https://console.cloudinary.com/
2. Получите **Cloud Name** (на Dashboard)
3. Создайте **Upload Preset**:
   - Settings → Upload → Upload presets → Add upload preset
   - **Signing Mode: Unsigned** ⚠️ ВАЖНО!
   - Preset name: `vigsharm_unsigned`
   - Нажмите Save
4. Скопируйте имя preset

### Шаг 2: Настроить админку (1 минута)

Админка уже открыта в браузере: `c:\vigsharm-shop\admin\index.html`

1. Перейдите на вкладку **Настройки**
2. Заполните поля:
   - **Worker API URL**: `https://vigsharm-api.vigsharm.workers.dev` ✅ (уже заполнено)
   - **Cloud Name**: `dxxxxx` (ваше значение из Cloudinary)
   - **Upload Preset**: `vigsharm_unsigned` (имя созданного preset)
3. Нажмите **Сохранить**

### Шаг 3: Создать первый товар! 🎉

1. Перейдите на вкладку **+ Создать**
2. **Шаг 1**: Загрузите фото (drag & drop или клик)
3. **Шаг 2**: (Опционально) Выберите сцену Studio Pro
4. **Шаг 3**: Нажмите **✨ Сгенерировать через ИИ** (заполнит поля автоматически)
5. **Шаги 4-7**: Проверьте и дополните информацию
6. **Шаг 8**: Нажмите **📢 Опубликовать товар**

## 🔧 Troubleshooting:

### Фото не загружаются
1. Проверьте настройки Cloudinary в админке
2. Убедитесь, что Upload Preset создан как **Unsigned**
3. Откройте консоль браузера (F12) для ошибок

### AI не генерирует
1. Проверьте баланс NordRouter API Key
2. Убедитесь, что фото загружено

### Worker не отвечает
```bash
cd c:\vigsharm-shop\worker
npx wrangler tail
```

### База данных пустая
```bash
npx wrangler d1 execute vigsharm-db --remote --command="SELECT COUNT(*) FROM categories"
```
Должно вернуть: 28
