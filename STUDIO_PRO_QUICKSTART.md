# 🎉 STUDIO PRO — БЫСТРЫЙ СТАРТ

## Что изменилось?

### ✅ Новая архитектура
**Было:** Каждое фото обрабатывается отдельно (долго, дорого, результаты разные)  
**Стало:** 1 фото → AI обработка → 3 готовых фото (быстро, дешево, результаты идентичны)

```
┌─────────────────────────────────────────┐
│  1. Загружаете ОДНО оригинальное фото   │
│                  ↓                       │
│  2. AI заменяет фон на эталонный        │
│     (бежево-серая стена + ламинат)      │
│                  ↓                       │
│  3. Получаете MASTER IMAGE              │
│                  ↓                       │
│  4. Автоматически создаются:            │
│     • Photo #1: Полная сцена (master)   │
│     • Photo #2: Только стена (crop)     │
│     • Photo #3: Стена + пол (crop)      │
└─────────────────────────────────────────┘
```

---

## Как использовать?

### Шаг 1: Загрузите фото
1. Откройте админку: `admin/index.html`
2. Перейдите на вкладку **"+ Создать"**
3. Загрузите **ОДНО** фото товара (drag & drop или клик)

### Шаг 2: Выберите режим
Выберите сцену для Studio Pro:
- **🤖 Автоматически** - AI сам определит
- **🏠 Напольная сцена** - стена + плинтус + пол (для фотозон, букетов)
- **🧱 Только стена** - без пола (для настенных композиций)
- **🎈 Шар поштучно** - студийное фото одного шара
- **💐 Букет в руке** - букет без пола
- **📸 Фотозона** - полный интерьер

### Шаг 3: Запустите обработку
1. Нажмите **"✨ Обработать фото через Studio Pro"**
2. Ждите 1-2 минуты (статус показывается под кнопкой)
3. Готово! У вас теперь 3 фото

---

## Что вы получите?

### Photo #1: Master Image
- Полная сцена с эталонным фоном
- Подходит для фотозон, букетов, крупных композиций

### Photo #2: Crop - только стена
- Убран пол
- Подходит для карточек в каталоге

### Photo #3: Crop - стена + пол
- Показывает стену и часть пола
- Подходит для напольных композиций

## Важно! Товар НЕ изменяется

Studio Pro заменяет ТОЛЬКО фон:
- ✅ Количество шаров - как было
- ✅ Цвета - как были
- ✅ Надписи - как были
- ✅ Композиция - как была

**Меняется ТОЛЬКО:**
- Стена → светлая бежево-серая
- Пол → серо-бежевый ламинат
- Освещение → естественное студийное

## Частые вопросы

### Q: Можно ли загрузить несколько фото?
A: Да, можете загрузить до 6 фото, но Studio Pro обработает **только первое** (главное) фото и создаст из него 3 варианта.

### Q: Что делать, если результат не понравился?
A: Загрузите оригинал снова и попробуйте другой режим или повторите обработку.

### Q: Сколько это стоит?
A: Один запрос к AI (модель `image/nano-banana-edit`). Crop Photo #2 и #3 создаются локально бесплатно.

### Q: Как долго ждать?
A: Обычно 1-2 минуты. Максимум 3 минуты.

### Q: Что если обработка зависла?
A: Проверьте консоль браузера (F12 → Console). Возможно, Worker не задеплоен или не установлен API ключ.

## Технические детали

### Файлы
- `admin/admin-studio-pro.js` - новая логика Studio Pro
- `admin/index.html` - обновлена кнопка
- `worker/index.js` - обновлены промпты
- `lib/studio-pro/` - модули для будущего

### API
- Endpoint: `/api/studio/process`
- Модель: `image/nano-banana-edit`
- Провайдер: NordRouter

### Crop
- Выполняется локально на Canvas
- Без дополнительных запросов к AI
- Формат: WebP, качество 92%
