## 📝 Изменения в коде

### Функция 1: `getProductPositioning()` (строки 7-107)

**Изменения:**
- `scale` → `targetWidth` (масштаб теперь по ширине, не по высоте)
- Добавлен `floorY` для floor-сцен (Y-координата "пола")
- Добавлен `useFloorAlignment` для выбора алгоритма позиционирования
- Новая логика для floor: нижняя граница объекта = floorY

**Новые параметры для floor:**
```javascript
floor: {
  targetWidth: 0.65,        // 65% ширины canvas
  centerX: 0.5,             // Центр по X
  floorY: 0.93,             // "Пол" на 93% от верха
  useFloorAlignment: true   // Выравнивать по низу объекта
}
```

**Новые параметры для остальных сцен:**
```javascript
wall_only: {
  targetWidth: 0.55,        // 55% ширины
  centerX: 0.5,
  centerY: 0.55,            // Центрирование по Y
  useFloorAlignment: false
}

unit_balloon: { targetWidth: 0.55, centerX: 0.5, centerY: 0.60 }
handheld_bouquet: { targetWidth: 0.60, centerX: 0.5, centerY: 0.65 }
```

---

### Функция 2: `getAlphaBoundingBox()` (строки 112-144)

**НОВАЯ ФУНКЦИЯ** — сканирует alpha-канал и находит реальные границы объекта.

**Алгоритм:**
1. Сканирует все пиксели imageData
2. Находит минимальные/максимальные X/Y непрозрачных пикселей (alpha > 10)
3. Возвращает `{ x, y, width, height }` — bounding box объекта

**Защита:**
- Порог alpha > 10 для защиты от шума
- Если не найдено ни одного непрозрачного пикселя, возвращает весь canvas

---

### Функция 3: `composeWithBackground()` (строки 262-356)

**Полная переработка алгоритма композиции.**

**Новые шаги:**

1. **Загрузка transparent PNG в temp canvas**
2. **Сканирование alpha-канала** → определение bounding box
3. **Обрезка прозрачных полей** → cropped canvas
4. **Вычисление позиции** для обрезанного объекта
5. **Композиция** фон + товар

**Детальные логи:**
```
[Canvas] ====== НАЧАЛО КОМПОЗИЦИИ ======
[Canvas] Transparent PNG: 1024x1024
[Canvas] Alpha bounding box: x=120 y=80 width=780 height=850
[Canvas] Cropped product: 780x850
[Canvas] Final product: 600x654
[Canvas] Position: x=212 y=300
[Canvas] FloorY: 952
[Canvas] ====== КОМПОЗИЦИЯ ЗАВЕРШЕНА ======
```

## 🎯 Какие параметры теперь можно менять

### Для точной настройки позиционирования:

**Файл:** `c:\vigsharm-shop\admin\admin-studio-pro.js`  
**Строки:** 11-59 (объект `positioning`)

#### Настройка для floor:
```javascript
floor: {
  targetWidth: 0.65,   // ← Размер товара (0.5-0.8)
  centerX: 0.5,        // ← Позиция по горизонтали (0.4-0.6)

}
```

```javascript
wall_only: {
  targetWidth: 0.55,   // ← Размер (0.4-0.7)
  centerX: 0.5,        // ← Позиция X
  centerY: 0.55,       // ← Позиция Y (0.4-0.7)
  useFloorAlignment: false
}
```

**После изменения:** сохранить файл и перезагрузить админку.
