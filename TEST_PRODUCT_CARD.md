## Как проверить результат

### Вариант 1: Через локальный сервер (рекомендуется)

1. Откройте терминал в папке проекта:
   ```bash
   cd c:\vigsharm-shop
   ```

2. Запустите локальный веб-сервер:
   ```bash
   python -m http.server 8000
   ```
   Или если есть Node.js:
   ```bash
   npx http-server -p 8000
   ```

3. Откройте в браузере:
   - **Товар 1**: http://localhost:8000/product.html?slug=nabor-den-rozhdeniya-devochka-6-let

### Если что-то не работает:

1. **Фото не загружается**
   - Проверьте, что файл `images/hero-balloon-character-party.webp` существует
   - Откройте консоль браузера (F12) и посмотрите ошибки

2. **"Композиция не найдена"**
   - Проверьте, что файл `assets/products.json` содержит правильные данные
   - Убедитесь, что используете правильный `slug` в URL

3. **Пустая карточка**
   - Откройте консоль браузера (F12)
   - Проверьте Network → XHR → `products.json`
