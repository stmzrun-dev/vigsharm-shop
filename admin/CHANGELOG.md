# VigSharm Admin - Обновление функционала

## Доработка (13.09.2026, вторая итерация)

### Исправлено главное: форма создания товара теперь отображается
Раньше контейнеры `#steps-nav` и `#product-form` были пустыми — JS ссылался на несуществующие элементы. Теперь в `index.html` размещён полный 8-шаговый визард:

| Шаг | Название | Поля |
|-----|----------|------|
| 1 | Фото | Drag & drop зона, галерея до 6 фото |
| 2 | Сцена и ИИ | Выбор сцены Studio Pro, кнопки «Обработать фото» и «Сгенерировать ИИ» |
| 3 | Базовая информация | Название, артикул, цена, описание, состав |
| 4 | Категория | Основная категория, персонаж, возраст, бюджет, серия |
| 5 | SEO | SEO-заголовок, SEO-описание, slug |
| 6 | Разделы каталога | Теги: Для кого / Повод / Даты / Тип |
| 7 | Опции клиента | Под заказ, цифра, надпись, аренда |
| 8 | Публикация | «Показывать на сайте», сохранить черновик / опубликовать |

### Новые возможности admin.js
- `setupSteps()` — кликабельная навигация по шагам (с отметкой «✓» для пройденных)
- `wireFormHelpers()` — автозаполнение артикула (DG-XXX) и slug из названия (транслитерация)
- `wireFilters()` — рабочие фильтры поиск / категория / статус
- `getFilteredProducts()` + `renderStats()` — фильтрация списка и статистика (всего/опубликовано/черновики)
- `toggleStatus(id, status)` — переключение «черновик ↔ опубликован» прямо из списка
- `saveProduct(status)` — единое сохранение: автозагрузка неотправленных фото в R2, POST для нового / PUT для редактирования, валидация с переходом на нужный шаг
- `showStep(n)` — переход к шагу со скроллом к карточке
- `newProduct()` — сброс формы и открытие вкладки создания

## Интеграция с worker API

Все функции используют `this.workerUrl` для обращения к API:

### Endpoints:
- `POST /api/products` - создание/обновление товара
- `GET /api/products` - список товаров
- `GET /api/products/:id` - получение товара
- `POST /api/upload/photo` - загрузка фото
- `POST /api/ai/generate-card` - AI генерация
- `POST /api/studio/process` - запуск обработки Studio Pro
- `GET /api/studio/status/:jobId` - статус обработки

## Использование

### Основной workflow:
1. **Шаг 1: Фото** - загрузка через drag & drop или выбор файлов
2. **Шаг 2: AI + Studio** - генерация данных и/или обработка фото
3. **Шаг 3: Данные** - заполнение или редактирование
4. **Шаг 4: Категория** - выбор категории и тегов
5. **Шаг 5: SEO** - мета-данные
6. **Публикация** или **Сохранить черновик**

### Валидация перед публикацией:
- Обязательно: название товара
- Обязательно: категория
- Обязательно: хотя бы 1 фото
