## 🚀 Как использовать

### 1. Настройка NordRouter API ключа

1. Откройте админ-панель: `http://localhost:8000/admin/index.html`
2. Перейдите на вкладку **"Настройки"**
3. В поле **"NordRouter API Key"** введите ваш ключ: `sk-nr-...`
4. Нажмите кнопку **"Сохранить"**
5. Проверьте, что появилось зеленое уведомление **"Настройки сохранены"**

**Проверка сохранения:**
- Откройте консоль браузера (F12)
- Выполните: `localStorage.getItem('vigsharm_admin_settings')`
- Должно вернуть JSON с ключом: `{"workerUrl":"...","nordrouterKey":"sk-nr-..."}`

---

### 2. Обработка фото через Studio Pro

1. Перейдите на вкладку **"+ Создать"**
2. **Шаг 1:** Загрузите фото товара
3. **Шаг 2:** Выберите сцену (например: "Напольная сцена")
4. Нажмите кнопку **"✨ Обработать фото через Studio Pro"**

**Что происходит:**
- Фото отправляется напрямую на `nordrouter.com/media/generate`
- Модель: `image/nano-banana-edit` (0.025$ за изображение)
- Опрос статуса каждые 3 секунды (до 3 минут)
- Фото автоматически заменяется на обработанное

**Индикаторы:**
- 📤 Отправка фото в NordRouter...
- ⏳ Обработка изображения... (1-2 минуты)
- ⏳ Статус: processing... (15с)
- ✅ Фото обработано через Studio Pro

---

### 3. AI генерация метаданных

1. После загрузки фото на **Шаге 2**
2. Нажмите кнопку **"🤖 Сгенерировать данные через ИИ"**

**Что происходит:**
- Фото анализируется через `openai/gpt-4o-mini` на NordRouter
- GPT-4o-mini с Vision анализирует изображение
- Автоматически заполняются все поля формы:
  - Название
  - Артикул
  - Цена
  - Короткое описание
  - Полное описание
  - Состав
  - Категория
  - SEO-заголовок
  - SEO-описание
  - Slug

**Индикаторы:**
- 🤖 Анализ фото через GPT-4o-mini...
- ✅ Метаданные успешно сгенерированы

## ⚠️ Возможные ошибки

### Ошибка: "Введите NordRouter API ключ в настройках"
**Решение:** 
- Перейдите в настройки
- Введите ключ `sk-nr-...`
- Нажмите "Сохранить"
- Обновите страницу (Ctrl+Shift+R)

### Ошибка: "HTTP 401" или "Unauthorized"
**Решение:** Проверьте правильность API ключа

### Ошибка: "Таймаут обработки"
**Решение:** Изображение обрабатывается более 3 минут. Попробуйте:
- Уменьшить размер фото
- Выбрать другую сцену

### Фото не обновляется после обработки
**Решение:** Проверьте в консоли браузера:
```javascript
app.currentProduct.photos[0].url
```

## 📊 Архитектура

### Старая (через Worker):
```
Браузер → Worker API → NordRouter
```

### Новая (прямая):
```
Браузер → NordRouter API
```

**Преимущества:**
- ✅ Нет зависимости от Cloudflare Worker
- ✅ Прямые запросы = меньше задержка
- ✅ Все запросы видны в DevTools
- ✅ CORS включен на стороне NordRouter

**Недостатки:**
- ⚠️ API ключ виден в браузере (DevTools → Network)
- ⚠️ Для продакшена лучше использовать Worker как прокси
