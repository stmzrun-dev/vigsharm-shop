🔍 Проверка модели Remove-BG в NordRouter

Что делает этот инструмент:
✅ Получает список моделей через Worker API
✅ Ищет модели для удаления фона (remove-bg, background removal)
✅ Показывает детальную информацию о найденных моделях
❌ НЕ запускает платную генерацию изображений
❌ НЕ изменяет код проекта
