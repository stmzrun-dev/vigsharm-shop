# VigSharm Admin Panel — Спецификация V3

## Архитектура

```
Админка (браузер)  →  Cloudflare Worker  →  NordRouter (AI + Studio Pro)
                         ↓                        ↓
                        D1 (товары)          GPT/Claude/Gemini
                        R2 (фото)            nano-banana-edit
```

- **Админка**: статический HTML/JS, хостится на GitHub Pages вместе с сайтом
- **Worker**: API-прокси, хранит ключ NordRouter, проксирует запросы
- **D1**: SQLite в Cloudflare — товары, категории, настройки
- **R2**: объектное хранилище — фотографии товаров
- **GitHub Actions**: только деплой

## Экраны админки

### 1. Список товаров (главная)

Таблица карточек товаров с колонками:
- Фото (миниатюра, 1-е фото = главное)
- Название
- Артикул
- Цена (₽)
- Категория
- Статус: Черновик / Опубликован
- Дата создания

Кнопки:
- **+ Создать товар** (зелёная, вверху справа)
- Редактирование (по клику на строку)
- Удаление (иконка корзины с подтверждением)
- Статус-переключатель (черновик ↔ опубликован)

Фильтры:
- Поиск по названию/артикулу
- Фильтр по категории
- Фильтр по статусу

### 2. Создание нового товара (модалка / отдельный экран)

#### Шаг 1: Загрузка фото
- Зона drag & drop: «Перетащите фото сюда или нажмите для выбора»
- Минимум 1 фото, максимум 6
- Форматы: JPG, PNG, WebP
- Максимум: 10 МБ на фото
- После загрузки: превью с возможностью:
  - Сделать главным (перетащить первым или клик «★»)
  - Удалить (иконка ✕)
  - Переупорядочить (drag & drop)

#### Шаг 2: Выбор сцены Studio Pro
Выпадающий список «Сцена Studio Pro»:
- **Определить по карточке и исходнику** (по умолчанию)
- **Шар поштучно · только стена**
- **Букет в руке · только стена**
- **Только стена**
- **Напольная сцена**
- **Фотозона**

#### Шаг 3: Базовая информация (AI заполняет)
Поля (AI предлагает, пользователь проверяет):
- **Название** (обязательно)
- **Артикул** (автоматически:DG-XXX, уникальный)
- **Цена** (₽, обязательное)
- **Краткое описание** (1-2 предложения)
- **Полное описание** (3-5 предложений)
- **Состав композиции** (буллет-лист компонентов)

#### Шаг 4: Дополнительная информация
- **Категория** (выбор из списка, обязательно)
- **Персонаж** (текст, опционально)
- **Возраст** (выбор: Для любого возраста / Для малышей / Для детей / Для подростков / Для взрослых)
- **Бюджет** (текст, опционально)
- **Тематическая серия** (текст, опционально)
- **Повод** (текст, опционально)
- **Целевая аудитория** (текст, опционально)

#### Шаг 5: SEO
- **SEO-заголовок** (AI предлагает на основе названия)
- **SEO-описание** (AI предлагает на основе описания)
- **URL товара** (slug, автоматически из названия, редактируемый)

#### Шаг 6: Дополнительные разделы каталога (чекбоксы)
Товар может отображаться в нескольких разделах:
- Для девочки, Для мальчика, Для неё, Для мамы, Для него, Геймерам
- Юбилей, 1 годик, Крещение, Гендер-пати, На выписку, Свадьба и девичник
- Выпускной, Новый год, 14 февраля, 23 февраля, 8 марта, 1 сентября
- Фигуры из шаров, Напольные композиции, Букет из шаров, Цветы из шаров
- Крафтовый букет, Шар-сюрприз, Коробка-сюрприз, Фотозона, Арка из шаров
- Шары поштучно

#### Шаг 7: Варианты для клиента (чекбоксы)
- **Доступен под заказ** — покупатель сможет отправить заявку
- **Выбор цифры** — клиент выберет цифру от 0 до 9
- **Персональная надпись** — клиент укажет свой текст
- **Аренда элементов фотозоны** — указать только то, что действительно возвращается

#### Шаг 8: Публикация
- **Показывать товар на сайте** (чекбокс, по умолчанию выключен)
- Кнопки: «Отмена» / «Сохранить черновиком» / «Опубликовать товар»

## Флоу Studio Pro (обработка фото)

### Вызов
1. Пользователь загружает фото
2. Выбирает сцену Studio Pro
3. Нажимает «✨ Подготовить фото Studio Pro»
4. Админка отправляет запрос на Worker

### Обработка
Worker делает:
1. Загружает фото в NordRouter (POST /media/upload) если не публичное
2. Отправляет запрос (POST /media/generate) с промптом и сценой
3. Поллит статус (GET /media/job/:id) каждые 3 сек
4. Получает result_url
5. Скачивает результат
6. Конвертирует в WebP
7. Загружает в R2
8. Возвращает URL результата в админку

### Промпт для Studio Pro (формируется на Worker)

Системный промпт:
```
Ты — профессиональный фотограф-ретушёр студии VigSharm (г. Армавир).
Твоя задача — подготовить фото товара для каталога.

СТРОГИЕ ПРАВИЛА:
1. ТОВАР НЕИЗМЕНЕН: количество шаров, форма, надписи, ленты, пропорции — ВСЁ как на фото. Обрезанное НЕ дорисовывать.
2. Фольгированная покупная фигура ≠ фигура из шаров (ШДМ). Не путать.
3. НЕ добавлять элементы, которых нет на оригинальном фото (стену, пол, букеты в руках).
4. Режим сцены определяется пользователем.

РЕЖИМЫ СЦЕНЫ:
- unit_balloon: один шар, чистый фон. Убрать водяные знаки/лого поставщиков. Принт шара не трогать.
- handheld_bouquet: букет в руках/без пола. Не превращать в напольную стойку.
- wall_only: строжайший запрет пола, плинтуса, ламината. Только стена.
- floor: каталожная стена + белый плинтус + серо-бежевый ламинат.
- photozone: полный интерьер со стенами.

ОБЩИЕ ТРЕБОВАНИЯ К ФОНУ:
- Стена: светлая нейтральная бежево-серая, мягкая текстура
- Плинтус: белый аккуратный (для floor и photozone)
- Пол: серо-бежевый ламинат (для floor и photozone)
- Тени: мягкие натуральные, без 3D-рендера
- Освещение: студийное, без желтизны ламп накаливания
- Глянец шаров: естественный (не стекло/пластик)
- Формат: квадрат или близкий к квадрату
- НЕ обрезать товар
```

## API Worker — Эндпоинты

### Базовый URL: `https://api.vigsharm.ru` (или поддомен Workers)

Все ответы: `{ "ok": true, ... }` или `{ "ok": false, "error": "..." }`

### AI endpoints

#### `POST /api/ai/generate-card`
Генерация данных карточки по описанию + фото.

Request:
```json
{
  "title_hint": "Цветочная фея",
  "price": 6000,
  "description": "Фигура из шаров в образе девочки с цветком",
  "scene": "floor",
  "image_url": "https://r2.../photo.jpg"
}
```

Response:
```json
{
  "ok": true,
  "card": {
    "title": "Цветочная фея",
    "article": "DG-043",
    "price": 6000,
    "short_description": "Фигура из шаров с лицом, косами, цветком...",
    "full_description": "Фигура из шаров...",
    "composition": ["• Фигура из шаров;"],
    "category": "Для девочки",
    "seo_title": "Цветочная фея — заказать шары в Армавире | VigSharm",
    "seo_description": "Фигура из шаров...",
    "slug": "cvetochnaya-feya",
    "tags": ["Фигуры из шаров", "Для девочки"],
    "client_options": {
      "available_on_request": true,
      "number_choice": false,
      "personal_inscription": false,
      "photozone_rental": false
    }
  }
}
```

#### `POST /api/ai/suggest-category`
Предложение категории по описанию.

Request: `{ "description": "...", "title": "..." }`
Response: `{ "ok": true, "category": "Для девочки", "tags": ["Фигуры из шаров"] }`

### Studio Pro endpoints

#### `POST /api/studio/process`
Обработка фото через Studio Pro.

Request:
```json
{
  "image_url": "https://r2.../original.jpg",
  "scene": "floor",
  "prompt": "дополнительные инструкции от пользователя"
}
```

Response:
```json
{
  "ok": true,
  "job_id": "cd88e737-...",
  "status": "processing"
}
```

#### `GET /api/studio/status/:job_id`
Проверка статуса задачи.

Response:
```json
{
  "ok": true,
  "status": "done",
  "result_url": "https://r2.../processed.webp"
}
```

#### `POST /api/studio/upload`
Загрузка приватного фото в NordRouter.

Request: multipart/form-data с файлом
Response: `{ "ok": true, "url": "https://nordrouter.com/media/file/..." }`

### Products endpoints

#### `GET /api/products`
Список товаров.

Response:
```json
{
  "ok": true,
  "products": [
    {
      "id": "uuid",
      "title": "Цветочная фея",
      "article": "DG-043",
      "price": 6000,
      "category": "Для девочки",
      "slug": "cvetochnaya-feya",
      "status": "draft",
      "photos": ["https://r2.../1.webp", "https://r2.../2.webp"],
      "main_photo": "https://r2.../1.webp",
      "created_at": "2026-09-12T10:00:00Z"
    }
  ]
}
```

#### `GET /api/products/:id`
Получение товара по ID.

#### `POST /api/products`
Создание товара.

Request: JSON со всеми полями карточки + photos (массив URL).

#### `PUT /api/products/:id`
Обновление товара.

#### `DELETE /api/products/:id`
Удаление товара.

#### `PATCH /api/products/:id/status`
Переключение статуса.

Request: `{ "status": "published" }` или `{ "status": "draft" }`

### Upload endpoints

#### `POST /api/upload/photo`
Загрузка фото в R2.

Request: multipart/form-data
Response: `{ "ok": true, "url": "https://r2.../uuid.webp", "id": "uuid" }`

#### `DELETE /api/upload/photo/:id`
Удаление фото из R2.

## D1 — Схема таблиц

```sql
CREATE TABLE products (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  article TEXT UNIQUE,
  price INTEGER NOT NULL DEFAULT 0,
  short_description TEXT,
  full_description TEXT,
  composition TEXT, -- JSON array
  category TEXT,
  character TEXT,
  age_group TEXT,
  budget TEXT,
  series_name TEXT,
  occasion TEXT,
  target_audience TEXT,
  seo_title TEXT,
  seo_description TEXT,
  slug TEXT UNIQUE,
  scene TEXT DEFAULT 'auto',
  tags TEXT, -- JSON array
  client_options TEXT, -- JSON object
  photos TEXT, -- JSON array of URLs
  main_photo TEXT,
  status TEXT DEFAULT 'draft', -- draft | published
  show_on_site INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  slug TEXT UNIQUE,
  description TEXT,
  sort_order INTEGER DEFAULT 0
);
```

## Правила (из памяти проекта)

### Studio Pro
- **PRODUCT IMMUTABLE**: товар неизменен (количество, форма, надписи, ленты, пропорции)
- 5 режимов сцены: unit_balloon, handheld_bouquet, wall_only, floor, photozone
- ИИ редактор, а не художник — запрещено дорисовывать несуществующие элементы
- Фольгированная покупная фигура ≠ фигура из шаров (ШДМ)
- slug и ID не ломать
- При смене названия менять только slug/title

### AI-генерация карточек
- 1 карточка = 1 запрос к ИИ
- ИИ предлагает данные, пользователь проверяет
- ИИ НЕ публикует автоматически
- ИИ не должен «угадывать» компоненты
- При повторном сохранении — не пересобирать объект целиком
