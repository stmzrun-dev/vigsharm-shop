# Как открыть админку

## Вариант 1: Python (самый простой)

Если у вас установлен Python:

```bash
cd c:\vigsharm-shop
python -m http.server 8000
```

Затем откройте: `http://localhost:8000/admin/`

## Вариант 2: Node.js (http-server)

Если у вас установлен Node.js:

```bash
cd c:\vigsharm-shop
npx http-server -p 8000
```

Затем откройте: `http://localhost:8000/admin/`

## Вариант 3: Открыть файл напрямую

Самый простой способ (но могут быть проблемы с CORS):

1. Откройте проводник
2. Перейдите в `c:\vigsharm-shop\admin\`
3. Найдите файл `index.html`
4. Откройте его в браузере (двойной клик)

⚠️ **Важно:** При открытии через file:// могут не работать некоторые функции из-за ограничений CORS.

## Вариант 4: Live Server в VS Code

Если у вас установлен VS Code:

1. Откройте папку `c:\vigsharm-shop` в VS Code
2. Установите расширение "Live Server"
3. Правой кнопкой на `admin/index.html` → "Open with Live Server"

---

## После запуска сервера

1. Откройте браузер: `http://localhost:8000/admin/`
2. **Нажмите F12** (откроется DevTools)
3. Перейдите на вкладку **Console**
4. Загрузите фото, нажмите "Обработать через Studio Pro"
5. Смотрите логи в консоли

---

## Альтернатива: Тест без админки

Если не получается запустить сервер, можно протестировать напрямую через API:

```bash
cd c:\vigsharm-shop
set NORDROUTER_API_KEY=ваш-ключ-здесь
node test-image-edit.js
```

Этот скрипт отправит запрос напрямую к NordRouter API и покажет результат.
