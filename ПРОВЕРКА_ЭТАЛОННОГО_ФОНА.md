# 🚀 ПРОВЕРКА: Эталонный фон Studio Pro

## Быстрая проверка (5 минут)

### 1. Открыть админку
```
http://localhost:8000/admin/index.html
```

### 2. Проверить консоль (F12)
Должно появиться:
```
✓ Cloudinary integration enabled
✓ Reference Background Manager loaded
✓ Vigsharm Admin Extended Functions loaded
✓ Studio Pro NEW ARCHITECTURE loaded
✓ AI Metadata Generator loaded
```

### 3. Перейти в Settings
- Вкладка **Настройки**
- Прокрутить вниз до **"🎨 Эталонный фон Studio Pro"**

### 4. Проверить UI
Должно быть видно:
- ⚠️ Эталонный фон ещё не загружен
- Кнопка "📤 Выбрать и загрузить фон"
- Кнопка "🗑️ Удалить"

### 5. Загрузить тестовый фон
- Нажать "📤 Выбрать и загрузить фон"
- Выбрать любое изображение (JPG, PNG)
- Дождаться загрузки

### 6. Проверить результат
После загрузки должно быть:
- ✅ Preview изображения отображается
- ✅ Статус: "✅ Эталонный фон сохранён"
- ✅ Появилась кнопка "🔄 Заменить фон"

### 7. Проверить localStorage
В консоли (F12):
```javascript
JSON.parse(localStorage.getItem('vigsharm_admin_settings'))
```

Должно содержать:
```json
{
  "workerUrl": "https://...",
  "cloudinaryCloudName": "saiuc42a",
  "cloudinaryUploadPreset": "vigsharm_unsigned",
  "studioReferenceBackgroundUrl": "https://res.cloudinary.com/..."
}
```

### 8. Проверить перезагрузку
- Закрыть и открыть админку снова
- Settings → "🎨 Эталонный фон Studio Pro"
- ✅ Preview должен сохраниться

### 9. Проверить Studio Pro (не должен сломаться)
- Вкладка "**+ Создать**"
- Загрузить фото товара
- Обработать через Studio Pro
- ✅ Должно работать как раньше

---

## Если что-то не работает

### Ошибка: "Cloudinary не настроен"
Settings → заполнить Cloud Name и Upload Preset → Сохранить

### Ошибка: "Upload preset must be whitelisted"
https://console.cloudinary.com/ → Settings → Upload → Upload Presets → 
Убедиться что preset = Unsigned

### Фон не сохраняется
F12 → Console → проверить ошибки

### Studio Pro сломался
Написать мне с текстом ошибки из консоли

---

## Готово! ✅

Если все 9 пунктов прошли успешно, эталонный фон готов к работе.

Следующий этап: композиция товара на эталонный фон.
