# Что делать дальше

## 1. Деплой обновленного Worker

Я добавил логирование для диагностики. Теперь нужно задеплоить:

```bash
cd c:\vigsharm-shop\worker
npx wrangler deploy
```

Дождитесь успешного деплоя (появится сообщение с URL).

## 2. Проверка через админку

1. Откройте админку: `http://localhost:8000/admin/`
2. Создайте товар, загрузите фото (например, с шарами)
3. **Откройте DevTools (F12)** → вкладка Console
4. Нажмите "Обработать фото через Studio Pro"
5. **Смотрите в консоль браузера** - появится лог:
   ```
   ✅ Получен result_url: {length: 234567, preview: "data:image/webp;base64,UklGR...", format: "base64"}
   ```

## 3. Сравните фото визуально

После обработки:

1. Правой кнопкой по фото → "Открыть в новой вкладке"
2. Сравните с оригиналом

**Важно:** Если фото визуально НЕ ИЗМЕНИЛОСЬ - это значит, что:
- ✅ Код работает правильно
- ❌ Модель `image/nano-banana-edit` НЕ ОБРАБАТЫВАЕТ изображение

## 4. Альтернативный тест (прямой запрос к API)

Я создал тестовый скрипт `test-image-edit.js`.

Запустите его:

```bash
cd c:\vigsharm-shop
set NORDROUTER_API_KEY=ваш-ключ
node test-image-edit.js
```

Он покажет:
- Создается ли задача
- Сколько времени обработка
- Размер результата
- Стоимость

## 5. Если фото действительно не меняется

### Вариант А: Попробовать другую модель

В файле `worker/index.js` строка 375:

**Было:**
```javascript
model: 'image/nano-banana-edit',
```

**Попробуйте:**
```javascript
model: 'image/nano-banana-pro',  // Дороже (0.0125$), но лучше качество
```

Или:
```javascript
model: 'image/seedream-5.0-pro',  // Другой провайдер (0.0083$)
```

### Вариант Б: Упростить промпт

Текущий промпт очень длинный (300+ строк правил).

Попробуйте простой промпт в строке 277-329:

