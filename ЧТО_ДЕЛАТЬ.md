# Что делать дальше - ПОШАГОВАЯ ИНСТРУКЦИЯ

## 🚨 ШАГ 0: Запустить локальный сервер

**Выберите один из вариантов:**

### Вариант 1 - Python (самый простой)
```bash
cd c:\vigsharm-shop
python -m http.server 8000
```

### Вариант 2 - Node.js
```bash
cd c:\vigsharm-shop
npx http-server -p 8000
```

### Вариант 3 - Тест БЕЗ админки (прямо через API)
```bash
cd c:\vigsharm-shop
set NORDROUTER_API_KEY=ваш-ключ
node test-image-edit.js
```

После запуска сервера переходите к шагу 1.

---

## ШАГ 1: Деплой Worker с логированием

```bash
cd c:\vigsharm-shop\worker
npx wrangler deploy
```

Дождитесь: `✨ Success! Uploaded...`

---

## ШАГ 2: Тест через админку

1. Откройте: `http://localhost:8000/admin/`
2. **Нажмите F12** → вкладка Console
3. Загрузите фото
4. Нажмите "Обработать фото через Studio Pro"
5. Смотрите в консоль - появится:
   ```
   ✅ Получен result_url: {length: ..., preview: "data:image/webp;base64,..."}
   ```

---

## ШАГ 3: Визуальная проверка

Правой кнопкой по фото → "Открыть в новой вкладке" → **сравните с оригиналом**

### Если фото ИЗМЕНИЛОСЬ ✅
Отлично! Проблема решена.

### Если фото НЕ ИЗМЕНИЛОСЬ ❌
Переходите к шагу 4.

---

## ШАГ 4: Упростить промпт (ЕСЛИ ФОТО НЕ МЕНЯЕТСЯ)

В файле `c:\vigsharm-shop\worker\index.js` найдите строки **277-329**.

Замените весь длинный блок с `const basePrompt = ...` на:

```javascript
const basePrompt = `Professional product photo for balloon catalog.

TASK: Replace background with white wall and wooden floor. Keep all balloons unchanged.

RULES:
- White smooth wall
- Natural wooden floor
- Soft lighting
- No logos
- Do not modify balloons`;
```

Затем снова деплой:
```bash
cd c:\vigsharm-shop\worker
npx wrangler deploy
```

И повторите тест (шаг 2-3).

---

## ШАГ 5 (опционально): Сменить модель

Если упрощение промпта не помогло, в файле `worker/index.js` строка **375**:

**Было:**
```javascript
model: 'image/nano-banana-edit',
```

**Попробуйте:**
```javascript
model: 'image/nano-banana-pro',
```
