## СЛЕДУЮЩИЙ ШАГ (5 минут)

### 1. Настройте Cloudinary
https://console.cloudinary.com/

**a) Cloud Name:**
Dashboard → скопируйте Cloud Name (например: `dxxxxx`)

**b) Upload Preset:**
Settings → Upload → Upload Presets → Add upload preset
- Name: `vigsharm_unsigned`
- Signing Mode: **Unsigned** ⚠️
- Folder: `vigsharm-products`
- Save

### 2. Сохраните в админке
http://localhost:8000/admin/ → Настройки
- Cloud Name: `dxxxxx`
- Upload Preset: `vigsharm_unsigned`
- Сохранить

### 3. Протестируйте
http://localhost:8000/admin/test-cloudinary.html
- Загрузить настройки
- Выбрать фото
- Загрузить → должно быть `✅ УСПЕШНО!`

### 4. Studio Pro
Админка → Создать → Загрузить фото → Studio Pro
Console (F12) покажет:
```
✅ CLOUDINARY UPLOAD SUCCESS
📸 Отправка в Studio Pro...
✅ Готово!
```
